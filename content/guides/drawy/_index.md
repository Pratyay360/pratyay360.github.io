# Drawy

Drawy is a collaborative drawing workspace built on [Excalidraw](https://excalidraw.com). Make an account, start drawing, and invite someone when you want company.

## Guides

| Guide | Description |
|-------|-------------|
| [Getting started](getting-started) | Create an account, draw your first canvas and invite someone to join it. |
| [Sharing and collaboration](sharing) | Share a canvas with a public link or another Drawy user, and follow the live edits. |
| [Libraries](libraries) | Reuse shapes across canvases by saving libraries from the public Excalidraw catalog. |
| [Privacy and security](privacy-and-security) | What Drawy stores, what it deliberately does not, and how to get rid of it. |
| [Self hosting Drawy](selfhost) | Run your own instance of Drawy — the TanStack Start app, the realtime worker and Postgres. |
