Forgit is a unified CLI for GitHub, GitLab, Gitea, Forgejo, Bitbucket, SourceHut, and other Git forges. Manage repositories, issues, pull requests, and more using one consistent set of commands across platforms without needing a separate CLI for each forge.

**Interact with different Git forges from your terminal.**

`forgit` Is a simple command-line tool for developers working across Git forges.

## Pick your package manager and install `forgit`.

### Mise

```bash
mise use github:github.com/pratyay360/forgit@latest
```

### Homebrew

```bash
brew trust --cask pratyay360/tap/forgit
brew install pratyay360/tap/forgit
```

### Scoop

```powershell
scoop bucket add pratyay360 https://github.com/Pratyay360/scoop-bucket
scoop install pratyay360/forgit
```

### WinGet

```powershell
winget install pratyay360.forgit
```

Prefer a direct download? Browse the [latest release.](https://github.com/Pratyay360/forgit/releases/latest)
