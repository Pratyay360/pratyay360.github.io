VN Video Editor (VlogNow) is a popular easy to use and free video editor available for the masses and used heavily by casual video editors.

But, Official Linux build doesn't exist. This unofficial AppImage packages the Windows version via Wine so it runs on Linux.

> ⚠️ **UNOFFICIAL COMMUNITY PROJECT**  
> This repository is an independent, community driven effort to create a portable AppImage wrapper for VN Video Editor on Linux. It is not affiliated with, endorsed by, or sponsored by Ubiquity Labs, VlogNow, or the official developers of VN Video Editor.

## Quick Start

```bash
# Download latest AppImage from releases
wget https://github.com/Pratyay360/vn-appimage/releases/download/0.6.3%402026-11-20_1795190491/vn-editor-0.6.3-anylinux-x86_64.AppImage
chmod +x vn-editor-0.6.3-anylinux-x86_64.AppImage
./vn-editor-0.6.3-anylinux-x86_64.AppImage 
```

```bash
# Option 1: Extract and run
./vn-editor-0.6.3-anylinux-x86_64.AppImage --appimage-extract-and-run

# Option 2: Environment variables
APPIMAGE_EXTRACT_AND_RUN=1 ./vn-editor-0.6.3-anylinux-x86_64.AppImage
```

It is suggested to use with some app image manager like [gear leaver](http://gearlever.mijorus.it/) or [appimage launcher](https://assassinate-you.net/tags/appimagelauncher/)

## Features

- 4K resolution export support
- Advanced keyframe animation
- Multi track timeline
- Effects, transitions, filters
- Text, stickers, overlays
- Audio editing (volume, fade, split)
- Export presets for YouTube, Shorts, TikTok
- No watermarks, no ads
