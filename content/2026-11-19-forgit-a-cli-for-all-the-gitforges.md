Forgit is one CLI for GitHub, GitLab, Gitea, Forgejo, Bitbucket, SourceHut, and other Git forges. Use the same commands to manage repos, issues, pull requests, and more on each platform, without a new CLI for each forge.

**Use many Git forges from your terminal.**

`forgit` is a simple command-line tool for people who use more than one Git forge.

## Choose a package manager and install `forgit`

### Mise

```bash
mise use github:github.com/pratyay360/forgit@latest
```

### Homebrew

```bash
brew trust --cask pratyay360/tap/forgit
brew install pratyay360/tap/forgit
```

### Scoop

```powershell
scoop bucket add pratyay360 https://github.com/Pratyay360/scoop-bucket
scoop install pratyay360/forgit
```

### WinGet

```powershell
winget install pratyay360.forgit
```

Need a direct download? See the [Latest release.](https://github.com/Pratyay360/forgit/releases/latest)
