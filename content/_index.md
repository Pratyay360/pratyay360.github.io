This site holds the setup guides, configuration notes, and reference pages for the open-source tools I build and maintain. Everything here comes from using the tools myself: install steps I have run, settings I have tested, and the problems I have had to solve.

If you are new, read **Getting Started with Projects & Tools** first for a short tour. From there, each project has its own page or guide with installation commands, examples, and answers to common questions. The Guides section collects the step-by-step walkthroughs.

The docs are plain Markdown in a [public Git repository](https://github.com/Pratyay360/pratyay360.github.io). If something is wrong or out of date, open an issue there. For other questions, use the contact link in the footer.
