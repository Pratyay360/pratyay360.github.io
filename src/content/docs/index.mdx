## How This Site Works

Everything here is written in Markdown and open source, hosted on GitHub at
[`Pratyay360/pratyay360.github.io`](https://github.com/Pratyay360/pratyay360.github.io). Pages are
built with Astro Starlight and served globally from [pratyay360.github.io](https://pratyay360.github.io/).

- **Contribute**: Found an error? Use the **Edit this page** link at the bottom of any document.
- **Search**: Looking for something specific? Press <kbd>/</kbd> to instantly search across all guides.
- **Quick Start**: New to the documentation? Jump right into [Getting Started](/getting-started/).
