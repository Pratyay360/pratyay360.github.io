Welcome to the documentation hub. Here you will find quickstarts, implementation guides, architectural diagrams, and practical examples for each active open-source tool and project.

## Project Guides & Quickstarts

Select a project below to jump directly to its setup instructions and reference documentation:

### 1. Dynamic UPI QR Code Generator
Generate instant, client-side, privacy-first Unified Payments Interface (UPI) payment QR codes and deep links using WebAssembly compiled from Rust.
- **[Dynamic UPI Getting Started Guide](/guides/upiqrcode/getting-started/)**
- **[How to Use & Parameter Reference](/guides/upiqrcode/how-to-use/)**

### 2. Ensor: Secrets Management & Redaction CLI
An interactive CLI tool built with Go, Huh, and Bubbletea that detects and redacts hardcoded secrets across your codebase and converts environment files between `.env`, JSON, YAML, and TOML.
- **[Ensor Documentation & Installation Guide](/guides/ensor/)**

---

### 3. Newsy: GitHub-Powered Newsletter Engine
A serverless newsletter delivery system powered entirely by GitHub Issues and Go/WASM. No expensive mailing list platforms or complex SMTP servers needed.
- **[Newsy Getting Started Guide](/guides/newsy/getstarted/)**
- **[Required Permissions & GitHub App Setup](/guides/newsy/list-of-all-permission/)**
- **[Development Roadmap](/guides/newsy/roadmap/)**

---

### 4. Drawy Whiteboard Ecosystem
Self-hostable, multi-tenant capable collaborative whiteboards powered by Excalidraw, available in three tailored editions:
- **[Drawy (Web & Supabase)](/guides/drawy/)** — Collaborative web application with multi-board management.
- **[DrawyParty (Cloudflare PartyKit)](/guides/drawy-party/)** — Ultra-low-latency real-time collaboration on Cloudflare edge.
- **[DrawX (Desktop Application)](/guides/drawx/)** — 100% private, offline native desktop whiteboard for Linux, macOS, and Windows.
